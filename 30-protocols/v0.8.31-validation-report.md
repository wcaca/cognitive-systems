## 1. N=30 真实 commit 误报率

### 方法

```bash
git log --oneline --since=2026-07-01 --until=2026-08-04 | head -30 \
  | awk '{print $0}' > /tmp/30-commits.txt

while IFS= read -r line; do
  msg=$(echo "$line" | sed 's/^[a-f0-9]\+ //')
  result=$(bash scripts/protocol-disambiguation.sh classify "$msg" 2>&1 | head -1)
  echo "[$result] $msg"
done < /tmp/30-commits.txt
```

### 统计

- **N = 30**
- **真协议 commit (期望 protocol)**: 14 个
- **非协议 commit (期望 non-protocol)**: 16 个
- **正确判定**: 13 (协议) + 15 (非协议) = 28
- **FN (协议 commit 漏判)**: 6 / 14 = **43%**
- **FP (非协议误判为协议)**: 1 / 16 = **6%**

### 关键观察

1. **FP 6%** (v0.8.25 是 71%) — v0.8.26 距离阈值 + v0.8.27 多语言 + 自发现 **3 版本叠加** 把误报从 71% 拉到 6%, **主目标达成**。
2. **FN 43% 集中在协议 commit 但 msg 无协议名**:
   - v0.8.30/29/28/27 都是协议文件自身 commit, msg 写的是"实做/调研/导出"等动词, 无协议名引用
   - v0.8.17/16/FixS 用了 "T/S" 单字母顿悟缩写, 白名单没有
3. **FN 修复方向 (v0.8.32+ 候选)**:
   - 协议文件自身 commit 用前缀 (30-protocols/) 已经能识别"是协议" — 加 `feat(30-protocols)` 模式直接视为 protocol commit
   - "T/S 顿悟" 缩写展开为 "T 顿悟/S 顿悟" 进入白名单

## 2. 跨语言协议名假阴性 = 0 验证 (v0.8.27 自查)

### 期望行为
v0.8.27 `multilingual-protocol-self-discovery.md` §触发:
> 协议名 = "中文|EN|JA" 多别名格式, 任一别名匹配即算协议引用

### 验证 2a — 纯日文 (无中文协议名)
```
[(空)] プロトコル同期失敗
[(空)] 洞察の検証
[(空)] 原則実装完了
[(空)] 飛輪の閉ループ
[(空)] 同期戦略
```
**结果**: 0 匹配. **预期行为** — 白名单 13 协议全是中文名, 纯日文文本里没协议名 (X 顿悟 vs X 頓悟 字符不同).

### 验证 2b — 纯西文 (无中文协议名)
```
[(空)] protocolo de sincronización
[(空)] principio del mirror
[(空)] sincronización cruzada
```
**结果**: 0 匹配. **同样预期** — 白名单无西文协议名.

### 验证 2c — 日文 + 日文协议名 (期望匹配)
```
[(空)] AA 頓悟のプロトコル同期
[(空)] X 頓悟の同期戦略
[(空)] Y 頓悟の検証
[(空)] Z 頓悟の閉ループ
```
**结果**: 0 匹配. **❌ v0.8.27 跨语言协议名未真正落地的证据**.
- 白名单 "X 顿悟" 是**中文"悟"** (U+6052), 日文协议写"X 頓悟"用**日文"悟"** (U+8A8C) — 不同字符
- PROTOCOL_MARKERS_JA 数组有"洞察/原則/同期/飛輪/閉ループ/プロトコル/実装"7 词, **但协议名只有中文版本**

### 验证 2d — 西文 + 中文协议名
```
[AA 顿悟] AA 顿悟 protocolo de sincronización
[X 顿悟]  X 顿悟  principio del mirror
[Z 顿悟]  Z 顿悟  sincronización cruzada
```
**结果**: 3/3 匹配 ✅. **西文+中文协议名工作** — PROTOCOL_MARKERS_ES 数组有 "protocolo/principio/sincronización", 离协议名 < threshold 距离.

### 跨语言协议名漏实现总结

| 语言  | 标记词 | 协议名多别名 | 实际工作? |
|-------|--------|---------------|-----------|
| 中文  | ✅ 16 词 | ❌ 只有中文 | 中文 commit 100% 工作 |
| 英文  | ✅ 10 词 | ❌ 只有中文 | 英文 commit 协议名引用不到 |
| 日文  | ✅ 7 词  | ❌ 只有中文 | 日文 commit 协议名引用不到 (頓悟 ≠ 顿悟) |
| 西文  | ✅ 3 词  | ❌ 只有中文 | 西文 commit 协议名引用不到 |

**v0.8.27 §触发 文档承诺 "协议名 = 中文|EN|JA 多别名格式"**, 但实现仅在 PROTOCOL_NAMES_CORE 13 项中**仅 1 项** ("镜子原则|mirror principle|mirror-principle") 含英文别名. 其余 12 项全是纯中文.

### v0.8.32+ 候选修复
