# v0.8.35 跨仓 FP/FN 验证报告: agent-memory + beauty-crm

**生成**: 2026-08-07 (凌晨 5 点长程)
**对比基线**: v0.8.31 报告 (cs 仓 N=30, FP 6% / FN 43% → v0.8.32 收口到 FP 0% / FN 8%)
**范围**: 跨仓 N=54 真实 commit (agent-memory N=30 + beauty-crm N=24)
**目的**: 验证 v0.8.32-34 协议识别在**非协议仓**上不误报

## 1. 方法

```bash
# 1. 拉跨仓 commit (取 7-1 后的, 跟 v0.8.31 报告范围一致)
cd /tmp/agent-memory
git log --oneline --since=2026-07-01 | head -30 > /tmp/am-30.txt

cd /tmp/beauty-crm
git log --oneline --since=2026-07-01 | head -30 > /tmp/bm-30.txt  # 实际 N=24

# 2. 跑 classify (cs 仓的协议识别器)
cd /tmp/cs
for repo in am bm; do
  cat /tmp/${repo}-30.txt | while IFS= read -r line; do
    msg=$(echo "$line" | sed 's/^[a-f0-9]\+ //')
    result=$(bash scripts/protocol-disambiguation.sh classify "$msg" 2>&1 | head -1)
    echo "[$result] $msg"
  done
done
```
